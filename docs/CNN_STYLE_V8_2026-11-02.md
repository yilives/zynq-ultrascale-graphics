# CNN 较强版边缘微调与板上验证（2026-11-02）

在用户已选择的 v7 较强漫画/版画、油画权重上继续微调，保持 **3→8→8→3、三层 3×3、INT8、160×96、1027 参数**。两套候选已完成实际 FPGA 推理、LCD 样点核对及原位流/菜单恢复。用户选定的 v7 文件保留，v8 尚未获得人工画质选择，也未替换普通菜单的默认配置。

## 本次改进

训练使用原来的 33 张训练图，在 9 张同世界验证图上选择检查点；历史测试图只作开发评估，没有将它们称为新的盲测集。额外取此前板上回读的 5 张输入作训练、选择之外的检查。

- 固定父模型的每输出通道二次幂量化尺度，减少微调时尺度切换带来的跳变。
- 增加按 RGB 强边缘加权的梯度误差，约束轮廓和纹理变化；保留参考艺术作品的 Gram 风格损失。
- 用父模型输出约束变化幅度；选型要求参考 Gram 距离最多变差 3%，平均 RGB 变化至少保留父模型的 90%。
- 添加 ±1 LSB 输入扰动约束；它只是静态敏感性训练，不能视作真实运动闪烁验收。

漫画、油画各训练 600 步，分别选择第 100、500 步。漫画后续检查点的边缘误差虽然更低，但参考风格距离退化超限，因此未选。

| 相对已选较强 v7 | 漫画/版画 v8 | 油画 v8 |
|---|---:|---:|
| 同世界验证集加权边缘误差下降 | 9.10% | 17.42% |
| 历史另一世界 8 图的边缘误差下降 | 8.78% | 17.76% |
| 5 张未参与本轮训练/选择的板上输入 | 8.69% | 7.13% |
| 参考 Gram 距离变化（越低越接近参考） | +2.86% | −0.004% |
| 平均 RGB 变化相对父模型保留比例 | 99.19% | 100.57% |

边缘误差衡量与原图梯度的接近程度；它不是艺术质量分数，上述下降比例不能解释成人眼画质提升百分比。漫画的参考风格距离有小幅代价，油画近乎持平。平均 RGB 变化也不能代替主观风格强度评价。

静态扰动在相同的 5 张板上输入上测量：漫画输出 RMS 从 1.273 降至 1.237 RGB 级、最大均为 6；油画为 1.038→1.039、最大均为 5，基本持平。尚无运动补偿的视频测试或人工闪烁确认。

## 实际 FPGA 验证

沿用已经验收的 NGR1 位流、分组输出和低 CPU 等待。运行链路为：

```text
RasterIX 400×240 源帧 → ARM 受保护快照/缩小到 160×96
→ PL 三层 INT8 CNN（v8 权重）→ ARM 低分辨率显示提交
→ PL 双线性五倍放大 → 800×480 LCD
```

本轮 FSR 关闭，CNN 与 FSR 仍未串联。实际位流与上一轮相同，原始配置 SHA256 为 `c7e5f78f059a68e679b8f2fed7a1284d81ea5f3fdd8fd93c2351b51f0fe8e4d2`。

| 板上 Neverball Level00 介绍场景 | 漫画 v8 | 油画 v8 |
|---|---:|---:|
| 已确认显示完成帧 | 248 | 249 |
| 短测 CNN 呈现吞吐 | 24.7548 FPS | 24.8261 FPS |
| 每帧推理平均耗时 | 9.322 ms | 9.327 ms |
| 卷积核心周期 | 462,816 | 462,816 |

相同 NGR1 的固定输入采用 v7/v8/v8/v7 顺序，两种风格各两张输入，共 16 帧。推理中位值为：漫画 v7/v8 **9.313/9.341 ms**，油画 **9.336/9.315 ms**。这组结果没有证明速度变化；本轮改善模型的轮廓指标，计算量、传输接口与核心时钟保持相同。

整机继续使用 NGR1 已布线配置：**65058 LUT、71711 FF、189.5 BRAM Tile、325 DSP**；本轮权重微调没有新增硬件，也没有把旧布线结果称为新综合结果。Vivado 工程仍为 `build/vcgr1/rix_cgr1.xpr`。

## 验证范围与证据

- 两种模型各 57 张训练/开发输入的 QAT 与独立整数参考一致；共核对 **14,008,320 个含填充通道的 INT8 值**。另对 5 张既有板上输入分别计算新旧模型。
- 从保存的 `.pth` 和 `model.json` 冻结量化尺度重新导出，部署配置字和全部 57 帧 RGB 输出一致，见 [检查点复现验收](../report/neural-style/quality-v8/checkpoint-acceptance.json)。重新加载此检查点应使用部署 JSON 中保存的尺度；复现脚本已落实该步骤。
- 既有 C++ 运行时的 8 组主机整数结果与 NumPy 黄金输出一致，见 [C++ 验收](../report/neural-style/quality-v8/host-acceptance.json)。
- 板上 16 帧固定输入共核对 **1,966,080 个 INT8 值**；两次实时测试末帧另核对 **245,760 个 INT8 值**。
- 回读两份原生 160×96 显示源，共 **122,880 字节**；核对 **12,000 个实际 LCD RGB565 采样点**。另外核对 768,000 个软件五倍显示参考像素；没有取得物理 LCD 的全像素抓取。
- GPU 读写错误、超时、下溢、扫描错误和快照过期均为零。两个游戏/后处理会话正常退出，原 FPGA 与原生清晰菜单恢复。

验收入口：[模型比较记录](../report/neural-style/quality-v8/comparison.json)、[板上独立验收](../report/neural-style/quality-v8/board-acceptance.json)、[原始回读证据](../report/neural-style/quality-v8/evidence.tar.gz)。证据归档 SHA256 为 `d61a4bf87841aa5133748e6891cfcf3c0d8c972cca1eabc5bf4377fdd52239da`。

这些结果是短时 Neverball 介绍场景的正确性与呈现验证，不代表完整游戏稳定 FPS、触摸操作或主观艺术质量验收。
