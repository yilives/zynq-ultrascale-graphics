# Java PL 路线：保持画质的命令缓存暂存实验

2026-10-28。用户要求保持当前画质继续优化PL渲染路线。本轮不降低设置，不改JAR、数学运算、FPGA位流或纹理通路，试验GPU命令的普通RAM暂存。默认入口和SD均保持原样。

## 澄清限帧策略

原版1.2.5选项fpsLimit:1的算法预算是目标120FPS，表示达到该速度后的限帧/更新策略，不代表系统实际能达到120FPS，更不会补帧。之前PL Tiny实测约25.72FPS。当前瓶颈下，两者不能混为一谈，本轮不改这个参数。

## 改动与边界

原PL像素渲染路线保留，候选只在A53与既有DeviceDataUploader之间增加独立IDevice适配层：生成GPU命令时写普通可缓存RAM，提交时等待真实DMA槽空闲，再将有效命令体整块memcpy过去，交回原上传器添加头并发起传输。纹理STORE/LOAD直接转交，不进入命令暂存。缓冲索引与容量受检，原上传与完成语义保留。

该方案优化的是PL渲染通路的命令生成/搬运，**没有改RTL像素核或将几何前端搬入PL**。此前每秒约25MiB命令及6.8MiB纹理，另有约29%DMA完成等待；它们是不同测量范围，不能简单相加或预先估计FPS增益。

宿主异步单元覆盖257字节和约1MiB容量，精确命令字节、提交后立即重用影子缓冲、异步真实槽、越界及纹理转交检查通过；首轮另在板上执行同份ARM程序。源码审计确认冻结核心归档/头文件、数学与原Sequential类正文不变，445个公共GL入口不变。几何字段单元证据复用来自未改动的计算源，不冒称针对新传输重新运行了几何算法测试。

候选库SHA-256：`1a1e061716489a384c819da130511d0187c48be3778cb72aa14883009091b794`；旧库`8e89c36f…`保留。新增运行时开关RIX_JAVA_CACHED_COMMANDS=0/1，两组均使用同一候选二进制，避免将重链接和开关收益混在一起。

## 画质与测量

400×240、完整256纹理、实际Tiny/Fast/关闭云、和平超平坦世界；AO开启、粒子全部、晃动开启、默认视场和亮度、高级OpenGL遮挡剔除及立体关闭，FSR/CNN关闭。上述选项直接从游戏对象读取，在暖机、计数开始与结束断言一致。

R81关、R82/R83开、R84关，连续ABBA。每轮同一冻结存档，60秒暖机后约30秒配对完成帧/单调时钟计数；保留整帧、双纹理、显示列表、满条带、在途资源删除与最终消费总量校验，正常退出后恢复原v23。四个新运行器各自通过Windows和Linux九项锁/回滚故障检查。

关闭首轮已测23.19FPS，较此前25.72FPS一组有变化。因此本轮只以同二进制开关组作收益对照，不与历史绝对值直接计算提升。

## PL计数器的实际含义与下一步

核对`CommandParser.v`，`perfBusy = state != COMMAND_IN`；顶层仅累加这一信号到32位`gpu_busy_cycles`。它并非“像素流水线正在有效着色”的计数，也不能把余下时间直接解释为整个GPU空闲。按设计100MHz归一化，本组命令解析器非COMMAND_IN状态约48.9%～51.9%；该频率来自设计约束，并未在本轮单独测量实际时钟。原始差值及取模边界已保存，但**不据此宣称FPGA只有一半利用率或尚可直接翻倍**。

继续保持画质的优先顺序：

1. **测清PL供数与有效工作。** 在独立硬件候选中，将已有`perfTriangleRendering`、`perfRasterizerStall`和输入有效/就绪空泡分别计数，经过RTL仿真、完整布局布线及板测后与同窗完成帧对齐。当前这两个信号尚未作为独立CSR统计交付，不能虚构其测量值。DMA等待墙钟也不能直接等价于纯光栅计算时间。
2. **减少现有前端的顶点搬运与重复读取。** 当前Tiny采样仍指向View::at和Vec搬运，应先验证同数学的批量路径与数值一致性，再用当前正确Tiny做完整ABBA。旧Far场景曾试验默认Vec值语义而未显著提速，不能将旧结果换标签，也不能预先承诺重试必然有效。
3. **再评估时钟与几何硬化。** GPU时钟域与其它时钟域须分别检查，不能只凭总WNS判断可提频。任何新频率都需对应的新约束、实现时序、实际运行时钟和恢复验证；也不能把光栅频率增幅直接称为游戏FPS增幅。矩阵/裁剪/三角形参数迁入PL为另一项硬件实现，受双TMU配置现有LUT/DSP余量限制，尚未完成或宣称加速。

当前仍是ARM游戏逻辑与几何前端→DMA→PL双纹理光栅、深度、混合→最近邻LCD输出。**本轮没有改RTL、没有新增几何硬件、没有开启FSR/CNN，也没有以降低画质换取帧率。** 原`8e89c36f…`库继续保留为既有推荐，`1a1e0617…`暂存库仅在RAM私有试验目录，开关关闭。最终原v23恢复、保护检查通过、无活动游戏客户端，SD未更新。
