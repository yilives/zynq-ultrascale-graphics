# Arm 神经超分在 XCZU3EG PL 上部署的可行性核对

日期：2026-10-23。本次是源码与架构核对，没有更换板端模型、运行游戏或重新编译 FPGA。

## 目标与当前状态

目标是将神经超分的卷积与像素重建部署在 FPGA PL，ARM 保留游戏逻辑、配置与调度。模型由 Arm 提供，与在 ARM CPU 上执行推理是两件事。

当前 MC 仍为 400×240 RGB565 原始渲染、160×96 FPGA 风格网络、800×480 显示；没有学习型超分。当前硬件风格核不是 Arm NSS，内部 NNS2 标识也不代表 Arm NSS。

## 两条不同的 Arm 模型路线

### Arm NSS：时域神经超分

Arm 发布了模型、预训练参数和训练工具；官方 SDK 面向 Vulkan，但这不意味着模型的计算在原理上无法用 RTL/HLS 重写。FPGA 移植必须重新实现模型及配套前后处理，不能将 VGF、SDK 库或权重直接装进现有风格核。

官方当前 SDK 要求匹配约定的颜色、深度、逐像素运动矢量、jitter 和上一帧输出；模型还涉及时间递归。RasterIX 有深度缓冲，但当前后处理路径没有供 NSS 使用的同帧深度导出、正确运动矢量、jitter 和历史重建协议。仅将缺失输入填零不能作为完整 NSS 接入或质量验收。

应先在主机取得完整算法与相同数据上的参考结果，锁定模型版本并统计算子、张量、MAC、DDR 访问和量化语义，再决定是否在该器件上实现完整 NSS、部分加速，或训练一个明确标注不同结构的学生网络。目前没有完成上述容量评估，不能承诺完整 NSS 能与 RasterIX、风格核同时放入 XCZU3EG。

### Arm SESR：单帧神经超分候选

SESR 是另一款 Arm 开源超分网络，不应称为 NSS。它的线性块在推理前折叠为卷积；官方提供权重与激活 INT8 的 QAT 流程。单帧输入不要求游戏增加运动矢量或历史重投影，因而更适合当前链路的首次硬件验证。

官方默认 SESR-M5 x2 使用单通道输入、16 通道中间特征，首尾为 5×5 卷积、中间为五个 3×3 块，另有残差相加、量化、裁剪和 depth-to-space。现有仅三层 3×3、8 通道的核不能直接执行它。浮点版本使用 PReLU，官方权重和激活均量化的路径改用 ReLU；不能忽略这一差异。

按上述折叠卷积计算，每个低分辨率像素需要：

`25×1×16 + 5×9×16×16 + 25×16×4 = 13,520 MAC`

400×240 每帧约 1.298 GMAC；30 FPS 约 38.94 GMAC/s。这只统计卷积，不包含残差、色度处理、搬运与显示，不能当作实测吞吐。也不能用官方相对其他模型的加速倍数推断本板速度。

如果缩减通道或层数，需要重训并单独命名为 SESR 派生模型；不得将它当成默认 SESR-M5 的等价实现。单通道网络还需明确 RGB/Y 色彩转换和色度放大，不能把单通道输出直接当 RGB 超分验收。

## 当前硬件的确定约束

`src/rtl/neural/rix_cnn_engine.sv` 当前有两组 `PIXELS×64-bit` 特征缓存，三层 3×3 卷积，固定 8 路通道计算结构；模型 ABI 和输出适配器也固定。

- 160×96 两组特征缓存的逻辑容量：245,760 B。
- 400×240 直接扩展后的逻辑容量：1,536,000 B，约 1.465 MiB。
- XCZU3EG 全部 216 个 36 Kib BRAM 的标称容量：995,328 B，约 972 KiB；其中还要容纳 RasterIX 等模块。

所以不能仅修改 WIDTH/HEIGHT 实现全分辨率推理。候选实现需使用行缓存、带正确 halo 的分块，或显式 DDR 特征存储，并核对边界、残差对齐及带宽。

最近完整布线 v4 报告为 LUT 47,216/70,560，BRAM 138/216，DSP 152/360，使用过的 CLB 8,520/8,820。CLB 使用比例约 96.6% 说明布局分散程度高，不等同于 LUT 已使用 96.6%；仍不能由空余 DSP 数量保证新增网络能布通。

## 建议实施顺序

1. 保持原始渲染 400×240、显示 800×480；避免同时改渲染分辨率和超分，方便归因。
2. 先完成单帧 2× 神经超分整数参考及实际 MC 数据质量对照；若选 SESR，锁定官方结构与量化方式，容量不合适时再明确建立派生模型。
3. 新增/适配 PL 卷积调度、5×5、残差及 PixelShuffle，采用分块或行缓存；复用已完成帧的所有权协议，数据经 DMA/AXI 在 PL/DDR 中传递，避免 CPU 逐像素 PIO 绕行。
4. 先独立验收超分，再评估与现有风格核复用乘加阵列或同时运行的成本。复用需要模型驻留/切换与调度设计，不能直接把两套模型吞吐相加。
5. 主机整数金值、RTL 仿真、整机布局布线和板端同帧像素/持续 FPS 逐级验证；没有板测前不承诺 30/60 FPS。

该路线验证的是 FPGA 神经超分。只有完整 NSS 输入与算法均接入并核验后，才能称为 Arm NSS 硬件化。
