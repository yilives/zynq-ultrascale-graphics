# CNTianQi233/th06-sdl2 与当前 RasterIX 项目的可行性核对

结论：**有移植价值，固定管线后端尤其值得复用；当前仓库不能直接当作本板 AArch64 成品替换已有引擎。** 本轮保留现有已运行的东方入口，同时将该项目作为正式版及练习功能的独立候选。未把源码审查、头文件编译或架构探针称为整机游戏运行通过。

## 已核对的源码与实际探针

用户给出的[上游项目](https://github.com/CNTianQi233/th06-sdl2)已检出到 `external/game-ports/th06-sdl2-review`，固定提交 `01642ba2690a6ab559e29268f5e1c1ed322e9e82`。本轮没有修改上游目录。

| 项目 | 实际结果 | 对本板的意义 |
|---|---|---|
| SDL2＋桌面固定管线 GL | 有，`src/sdl2_renderer.cpp` | 比仅提供 GLES3 的候选更接近当前 RasterIX |
| 渲染接口 | 有 `IRenderer` | 可以增加专用后端，但不能只看接口文件就认定全部图形调用已解耦 |
| 正式版目标 | v1.02h | 仍需要匹配的原作 DAT，代码仓库不能替代正式版数据 |
| 练习模式与编码 | 包含 thprac、GBK/Shift-JIS 处理 | 能改善关卡练习与中文使用体验，但需独立兼容验证 |
| 原样 AArch64 编译参数 | **失败**：SDK 报 `unrecognized command line option '-m32'` | 原构建没有直接覆盖本项目的 AArch64 目标 |
| 去掉该参数后的头文件探针 | 编译通过 | 仅证明该头文件能被 AArch64 编译器解析，不证明游戏逻辑和资源装载正确 |
| 64 位结构探针 | 指针 8 字节，`AnmVm` 288 字节；8 字节磁盘脚本项与对应原生指针结构 16 字节 | 需要逐项审计磁盘偏移与运行时指针，不能仅删 `-m32` 后忽略布局 |

探针脚本：`scripts/probe_th06_sdl2.sh`；完整输出在 `build/library-v4/th06-sdl2-review/`；机器可读记录在 `report/library-v4/th06-sdl2/source-audit.json`。这里的 `NativeScript` 是用于说明指针布局差异的小结构，不代表已证明上游每一处解析都会出错；上游已有按 u32 读取部分脚本偏移的处理，仍需全面检查。

当前 SDK 为 GCC 9.2，上游 README 建议 Linux GCC 13+ 或 Clang。后续还要确认实际使用的编译器特性；不为一个游戏直接升级整套已验收的内核/SDK。

## 图形接口的具体差距

1. **FBO。** 桌面后端使用 FBO 做尺寸变化时的离屏绘制，但源码包含直接绘制回退。因此不能把“必须给 FPGA 增加 FBO”当作先决条件。首版应直接绘制到当前 400×240，再交给已有 PL FSR/显示链路。
2. **纹理回读与透明度。** 使用 `glReadPixels`、`glGetTexImage` 等；`AnmManager.cpp` 中也有直接 GL 纹理调用。只实现 `IRenderer` 仍可能遗漏这些路径。应在 ARM 保留纹理副本并复用现有透明度处理和图集分页，避免同步读回拖慢游戏。
3. **纹理尺寸。** 当前硬件支持的最大纹理为 128×128，已有 TH06 后端通过图集分页处理。新项目不能直接假设原始大纹理或 ImGui 字体图集可上传。
4. **练习覆盖层。** thprac 的 Dear ImGui 渲染需要单独适配顶点、索引、剪裁和字体。可先关闭覆盖层跑通原游戏，再逐项恢复，不能直接宣称练习界面已可用。
5. **GLES2 与 Vulkan。** 它们属于候选的其他后端，不是现有 RasterIX 的即插即用接口。GLES2 可作为另一路 Mali 研究，Vulkan 不作为本板当前实现目标。

## 推荐落实顺序

优先用现有已经过 AArch64/RasterIX 验证的引擎导入正式版数据，按版本控制三关限制，验证后续关卡、Extra、结局、成绩和回放。在独立目录中对本候选完成 AArch64 布局审计及最小固定功能渲染，再比较是否值得整体替换；练习菜单、编码与输入改进可分别借鉴。

若保持候选的 32 位布局，另一条路线是 ARM32 用户态，但还需要 ARM32 工具链、SDL/图形库以及内核/驱动兼容 ioctl 验证。它不能用 x86 的 `-m32` 参数直接代替，也不是当前最快的正式版接入路线。

当前已校验的素材仍是官方 0.13 体验版；本轮检出的候选仓库未找到 DAT 运行数据。正式版实际运行仍取决于提供匹配的 v1.02h 数据目录。原体验版包、已有较强 CNN、PL FSR 和原位流继续保留。
