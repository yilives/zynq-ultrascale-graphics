# CNN 风格质量第六轮探索

2026-11-01。**本轮完成模型训练、独立整数比对和同帧管线诊断，没有把未通过筛选的权重替换到板上。** 清晰菜单和三游戏 FSR 已正常部署，CNN 仍不在该菜单的游戏后处理链路中。

## 先看效果在哪里丢失

以下对照使用历史已保存的真实 MC 输入，在 PC 上计算。每行从左到右为：原图、完整教师网络、当前小 CNN 直接输出、当前保护融合、较强融合预览。**教师网络在 PC 执行；后两列是离线整数/融合参考，不能当作本轮 FPGA 新模型的实测截图。**

![动漫管线同帧对照](../report/classicube-style/quality-v6/anime-pipeline-28.png)

![油画管线同帧对照](../report/classicube-style/quality-v6/oil-pipeline-28.png)

完整油画教师能够产生明显的颜色结构和笔触，小 CNN 直接输出已经丢失很多这些特征，后续残差融合又降低了风格强度。由此判断，问题不能仅靠增大最后的混合强度解决。

对现有 36 张开发图统计，世界区域中被边缘掩码完全抑制的像素约 **2.26%**。这不支持把效果弱主要归因于“所有纹理都被保护掉”；网络容量、低分辨率输入和整体融合权重均有影响。保护矩形仍不是引擎提供的真正 HUD 图层。

较强融合预览使用强度 192/256、边缘最小权重 64/256，并保留保护矩形。它仅用于观察已有 CNN 修正被放大后的结果，**不是新模型、不是已部署功能，也未通过艺术质量或闪烁验收**。

## 已完成的训练与取舍

训练使用历史 v5 的 17 张训练图、9 张同世界验证图，以及其训练/验证光流配对；没有借用验证图训练。其他历史图均只当开发对照，本轮没有新的独立世界留出，不能把指标当作泛化或人工审美验收。

| 实验 | 实际结果 | 决定 |
|---|---|---|
| 原三层动漫结构，1200 步 | 联合图像/运动目标未超过 v5，选回第 0 步；输出与 v5 相同 | 保留 v5 |
| 原三层油画结构，1200 步 | 同一保护融合下，验证教师 MAE 14.6858 → 14.6544，约改善 0.214% | 收益太小，不替换 |
| 六层、8 通道动漫结构，1800 步 | 最低图像 MAE 检查点约改善 4.89%，运动残差变化代理恶化约 46.04%；联合目标仍选回初始模型 | 不采用 |

三层输出和六层输出均通过独立 INT8 计算与 QAT 输出逐值一致检查。数值正确不能代替风格满意或移动稳定。

六层结构在两层已有正值特征后插入三层恒等卷积，初始化精确保持旧网络。训练确实执行了 1800 步；最终选择第 0 步，新增层仍为恒等，36 张图最终输出与旧模型相同。**13×13 是候选拓扑的理论感受野，不应把这次选回初始模型描述成已获得更大有效感受野或画质升级。**

六层试验不兼容旧模型 ABI，使用独立 JSON 标记，未生成可交给旧加载器的 RIXCNN1 权重。顺序复用旧 64 路、100 MHz 核心的粗估计算时间约 8.29 ms，特征双银行约 245,760 字节；这不包含搬运、接口修改、综合和布线，也不说明当前 FSR 组合能直接装下或达到某个 FPS。

## 全局上下文候选

源码检查发现：CNN 核心内部已有 8 条有符号特征输入，但当前 AXI PIO 输入只写 RGB，高 5 通道强制清零。新增离线候选使用：

```text
8 路输入 = RGB 3 路 + 当前帧平均 RGB 3 路 + 归一化 X/Y 2 路
网络 = 8 → 8 → 8 → 3
```

该拓扑利用已有物理输入乘法通道，核心 MAC 调度及特征银行尺寸理论上不变。**当前 AXI 适配器仍只能送 RGB，需要扩展输入寄存器/协议，不能只改 Python 或换权重启用。** 还需要重新综合、时序与完整 FPGA 数值验证；本轮未部署或声明资源适配已通过。

模型采用不同的 `RIXCTX1` 头和 `.ctx` 扩展名，旧运行时应拒绝加载。全图均值与位置先在完整图上确定，再裁剪训练输入，避免每个训练块使用不同坐标或统计值。

首次上下文训练在首个日志点后宿主命令返回 -1，未产生完成模型；原目录和日志保留，记为失败。随后切换到连续 NCHW 内存、两个 CPU 线程和非 MKLDNN 路径，完成了 12 步稳定性检查及 36 张图独立整数比对。该短检查不能作为训练收敛或画质提高的证据。后续有界训练结果单列在 `context8-stable/training.json`。

随后完成 **400 步动漫上下文训练**，36 张图 QAT/独立整数输出零差异。验证联合目标仍未超过原 v5，最终选择第 0 步，因此本轮没有取得新的可替换权重。该结果只覆盖这组小数据和训练设置，不能据此否定全局上下文方法；也不能把接口可扩展性当作已证明的画质收益。
