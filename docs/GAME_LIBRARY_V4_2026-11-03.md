# 15 款游戏库 v4：新增游戏、菜单和实机验证

本轮将原有八个入口扩展为十五个：新增 **rRootage、贪吃蛇、落块消行、打砖块、2048、推箱子、扫雷**。其中 rRootage 是上游完整开源游戏，六款经典小游戏是本项目新增的原生规则实现，分别包含可游玩规则、胜负/结束、重新开始与输入。没有将候选项目、未安装素材或新增球场当作新增游戏计数。

原有 Tux Racer、Neverball、Neverputt、Quake、Quake III、红魔乡体验版、ClassiCube、Minecraft Java 保留。正式版东方未冒充已接入；对用户提供的新引擎评估见 [TH06 SDL2 可行性核对](TH06_SDL2_FEASIBILITY_2026-11-03.md)。

## 新游戏内容

| 游戏 | 已实现/保留内容 | 实机源呈现短测 |
|---|---|---:|
| 贪吃蛇 | 增长、食物、反向保护、尾部腾空判定、碰撞、最高分 | 约 60 FPS |
| 落块消行 | 七袋随机、旋转与墙边尝试、消行计分、下一块、落点影子、软/硬下落 | 约 60 FPS |
| 打砖块 | 砖块碰撞、挡板角度、三条生命、三轮关卡、重新发球 | 约 55 FPS |
| 2048 | 每步只合并一次、新方块、计分、一步撤销、结束判定 | 约 60 FPS |
| 推箱子 | 六个经求解器验证可解的关卡、推箱/目标、撤销、完成后下一关 | 约 55 FPS |
| 扫雷 | 9×9、10 雷、首次点击及其邻域安全、洪水展开、插旗、连开、胜负 | 约 60 FPS |
| rRootage | 原版弹幕脚本、四种模式、敌舰、激光、特殊能力、成绩保存 | 约 40 FPS |

这里使用硬件 `presented` 计数与单调时钟，在取景前窗口计算，并非游戏 HUD 的循环 FPS；均为关卡短测，不能扩展为全部场景稳定帧率。原八款沿用各自既有验收，本轮新增七款另行实际运行。rRootage 使用明确的静音后端；本轮不包含音频输出验收。

六款经典游戏的规则位于 `ports/arcade/rules.hpp`，统一的固定功能绘制位于 `ports/arcade/main.cpp`。ARM 承担规则、输入及现有顶点前端，RasterIX 完成三角形、纹理和混合绘制。程序只使用 GL 绘制，不将 CPU 软件帧缓冲当作 FPGA 游戏光栅化。字体在启动时准备到纹理中；本轮没有更改 RTL、综合新位流或增加按游戏数量分配的 FPGA 模块。

![七款新增游戏的实际 GPU 源帧](../report/library-v4/new-games-board.png)

这是首轮 GPU RGB565 源帧回读，与每款 6000 个 LCD 样点核对。小字随后完成独立修复，首轮原始证据保留。

## 菜单扩容

游戏库保留原生 **800×480** LCD 输出，增加：

- 每页八张卡片，方向键可跨页；PgUp/PgDn、鼠标滚轮及上下页按钮均可翻页。
- 名称/ID/描述关键词搜索，支持目录中的中文及 ASCII 大小写不敏感匹配；按 `/` 开始输入。
- 收藏筛选与持久保存；最近启动项优先显示。
- 动态游戏数量，素材/运行包不满足身份检查时不允许启动。
- 原有 FSR 开关、独立存档、正常退出与返回机制。

当前 GUI 的风格开关没有自动接入 CNN。上一轮七游戏 CNN＋FSR 实验入口继续独立保留；不能把这次十五款菜单数量当成十五款 CNN 全部完成。

## 修复了新小游戏的小字采样

首轮实际回读发现 1 像素字体存在缺笔。将图集改为每个逻辑像素两个纹理 texel，增加最近邻采样余量，并修正纵向采样相位。最终 “SNAKE GARDEN” 区域 **504 个字符位图像素逐点一致、零差异**，另有 6000 LCD 样点一致。规则与旧版本保留，最终六游戏共享修复后的引擎。

![小字采样前后实机回读](../report/library-v4/font-sampling-compare.png)

此修复作用于新增小游戏自己的 GL 字体；总菜单仍使用原生 CPU 字形栅格与 POST 双缓冲。

## 验收和部署范围

主机已完成六游戏规则验证、22 项 UI 交互的双尺寸检查、11 组会话/输入/交接检查、三个 GL 参考图案，以及 384000 像素原生转换检查。首次七游戏实机验证包括实际玩法、源帧、**42000 个 LCD 样点**、正常关闭和原菜单恢复；最终字体另行验收。

最终集成已通过，机器可读结论见 [acceptance-final.json](../report/library-v4/acceptance-final.json)：

- 七款新增游戏均实际运行 PL FSR，使用 FPGA EASU12＋RCAS5 定点后端；没有使用 CPU 像素处理替代。每个输出对应不同源帧，重复源帧及快照租约过期均为零。
- 总菜单正常启动推箱子、开启 FSR 的 rRootage，以及原有 Neverball；均以正常运行方式启动，未启用 QA 自动游玩，注入输入后正常关闭并恢复配置和菜单。
- 两页菜单累计 768000 原生像素、12000 LCD 样点一致；字体独立 6000 样点，加上七游戏首轮 42000 样点，共 60000 个 LCD 样点。
- 15 个入口全部就绪；139 个运行文件逐一核对长度和 SHA-256，与完整运行包一致。GPU 读写、超时、欠载和扫描错误均为零。

新增正常游玩配置位于板端 `/opt/rasterix/experimental/profiles/library-v4/<game>`；最终七款自动游玩测试使用 `/tmp/rasterix-library-qa-profiles/<attempt>`。正常菜单切换使用对应游戏既有的正常配置路径，不自动抹除玩家存档。最初的新增游戏诊断曾使用独立的新游戏配置目录，旧记录保留。SD 启动包未重写；BOOT.BIN、system.dtb、原有漫画/油画 CNN 模型及私有 GL 库在最终状态核对原哈希一致。

当前运行采用独立 RAM 目录 `/tmp/rasterix-launcher-v4-library`，已保留新版菜单运行，原 v3 目录保留。重启后的整套恢复仍依赖已有 BSP、素材缓存、FSR 加载流程及 Java 的 RAM 依赖，不宣称已完成冷启动自启动。miniDP 未实接，本轮实际输出针对 RGB LCD；键鼠通过 XTEST 自动输入验证，实物键鼠尚未验收。

## 构建与来源

```powershell
./build.ps1 -Action launcher
```

入口改为 `scripts/build_launcher_library.ps1`，输出 `build/launcher-v4-library/`，不覆盖已验收的 v2/v3/CNN/FSR 包。完整包是 `rasterix-library-v4.tar.xz`，运行文件索引为 `runtime-manifest.json`。

完整包 SHA-256 为 `53ae0c860f85611966a887de843a96af3d3033f172106d9126e9ebdc89291be6`；最终证据包 `report/library-v4/final-evidence.tar.xz` 为 `7d70a4b5cc0b679dd08d32c870185e19634cf802752c69de0e736d343d82254a`。`build-proof.json` 保留构建阶段的待上板状态，实际上板采用记录另见 `build/launcher-v4-library/board-adoption.json`，避免混淆构建通过与实机通过。

本次实际串口安装使用首版增量包与 6068 字节修复补丁；本机同时生成了修正后的单一增量包，但未声称该单一文件已整包上传。最终逐文件索引核对证明实际 RAM 运行文件与完整包一致。

主机复核可执行 `python scripts/accept_library_final.py`；它校验原始证据索引、两页完整显示像素、七项硬件 FSR、三项正常切换及运行文件身份，不要求开发板重跑已通过的测试。

rRootage 固定到作者仓库提交 `1a4e316f0791b16492597f502426352bcacd1f89`；BulletML 固定到 PSP 移植仓库提交 `5313166eee9c9126873795dd6ac16e28b63e6f65`。SDL1 窗口/输入适配至 SDL2，恢复桌面双精度回调接口，提供最小 GLU 数学兼容层，并记录静音选择。上游源码、许可与素材保持独立；本项目补丁在单独工作目录生成。

首轮七游戏证据、最终字体证据、源码/ABI 探针和最终菜单/FSR 集成记录都在 `report/library-v4/`。Kobo Deluxe、Chromium B.S.U. 仍属于下一批候选，没有计入当前十五款。
